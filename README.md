# E-commerce — Aplicação Web

Este projeto é um e-commerce fictício desenvolvido com Next.js, com foco em performance, organização de código e boas práticas de front-end moderno.

A aplicação simula uma loja virtual completa, com páginas de produtos, listagem, navegação dinâmica e estrutura preparada para integração com APIs e meios de pagamento, sem depender de um backend real.

## ✨ Tecnologias utilizadas
- Next.js
- React
- Tailwind CSS
- JavaScript / TypeScript
- HTML5
- CSS3

## 🎯 Objetivos do projeto
- Praticar desenvolvimento de aplicações com Next.js
- Explorar rotas, páginas dinâmicas e componentização
- Aplicar conceitos de UX em e-commerce
- Criar um projeto realista para portfólio

## 📌 Observação
Este é um projeto fictício, desenvolvido exclusivamente para fins de estudo e portfólio.
